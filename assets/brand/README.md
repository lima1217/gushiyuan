# Brand assets

- `app-icon-source.png` — master app mark (may include design-tool padding / squircle).
- Ship icons are generated by `scripts/generate-app-icons.py` into `src/app/icon.png`, `src/app/apple-icon.png`, `public/icon-512.png`, and `public/icon-maskable-512.png`.

Generated icons are full-bleed opaque RGB on paper (`#faf8f4`) so iOS / Android home-screen masks do not leave a white ring.
